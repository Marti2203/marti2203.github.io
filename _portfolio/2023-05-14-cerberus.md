[Cerberus](https://github.com/nus-apr/cerberus) is a research acceleration platform providing a unified interface to multiple state-of-the-art program analysis tools, including fuzzing, static analysis, and automated program repair. Presented as a tool demonstration at ICSE 2023 — see the [publication](/publication/2023-05-14-cerberus-program-repair-framework) for details.
